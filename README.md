# Practicum_projects

Учебные и проектные работы, выполненные в рамках курса «Junior Frontend» в Яндекс Практикуме.

Здесь собраны проекты, которые показывают мой путь от вёрстки до SPA на React: адаптивные интерфейсы, работа с API, архитектура приложений, тестирование и анимации.

---

## 🚀 Проекты

| Проект | Описание | Стек |
|---|---|---|
| [Stellar Burgers](./stellar-burgers) | SPA для конструктора бургеров с авторизацией, WebSocket и тестами | React, Redux Toolkit, TypeScript, React Router, Jest, Playwright |
| [Web-ларёк](./weblarek) | Интернет-магазин с корзиной и двухшаговой формой заказа (MVP) | TypeScript, ООП, EventEmitter, REST API, Vite |
| [SkillSwap](./skillswap) | Командная разработка веб-приложения с нуля | React, TypeScript, Git |

| [Сложно сосредоточиться](./slozhno-sosredotochitsya) | Адаптивный сайт с тёмной/светлой темой и автопереключением | HTML5, CSS3, CSS-переменные, prefers-color-scheme |
| [Закрывающий тег](./zakryvayushchiy-teg) | Блог с SVG-анимациями, модальным окном и CSS-фильтрами | HTML5, CSS3, SVG, `<dialog>`, @keyframes |

## 🛠 Что я умею

- Адаптивная и кроссбраузерная вёрстка (Flexbox, Grid, CSS-переменные, clamp)
- SPA на React (Hooks, Redux Toolkit, React Router v6)
- Работа с REST API, асинхронность, валидация форм
- WebSocket (лента заказов в реальном времени)
- Типизация на TypeScript, ООП, паттерны проектирования (MVP, EventEmitter)
- Тестирование: Jest (юнит), Playwright (E2E)
- Сборка на Vite, Git, Bash
- Чтение и доработка чужого кода, рефакторинг, документирование архитектуры
